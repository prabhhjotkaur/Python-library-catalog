# Library Catalog System

A modern, clean web and desktop application for library catalog management built using Python Object-Oriented Programming (OOP) concepts.

## Features
- **100+ Curated Books:** Comprehensive collection spanning Fiction, Non-Fiction, and Reference textbooks with real book cover artwork.
- **Search & Filtering:** Real-time search across titles and authors, plus filtering by category and availability status.
- **Borrowing & Return System:** Dynamic status tracking with built-in borrowing rules (e.g., Reference materials restricted to in-library use).
- **Core OOP Architecture:** Built strictly using Classes, Encapsulation (private status attributes), Inheritance, and Polymorphism.
- **Dual Interface:** Run as a modern web app (Flask + Tailwind CSS) or as a native desktop GUI (Tkinter).

---

## How to Run

### 1. Clone or Download the Repository
```bash
git clone https://github.com/prabhhjotkaur/Python-library-catalog.git
cd Python-library-catalog
```

### 2. Install Required Dependencies
Ensure you have Python installed, then run:
```bash
pip install -r requirements.txt
```

### 3. Start the Web Application
```bash
python app.py
```
Open your web browser and navigate to:
```
http://localhost:5001
```

*(Optional: To run the native desktop Tkinter interface, run `python gui.py`)*
