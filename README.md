# Library Catalog System

A clean, modern web application for library catalog management.

## Features
- **100+ Curated Books:** Covers Fiction, Non-Fiction, and Reference books with high-resolution cover artwork.
- **Search & Filtering:** Real-time search across titles and authors, plus filter by category or availability.
- **Borrowing & Returns:** Immediate status updates with restrictions on reference materials.
- **OOP Core:** Built on Python OOP principles (Classes, Encapsulation, Subclasses, Polymorphism).
